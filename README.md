### Selected Projects

- **[dropoutt-cli](https://github.com/ckproduces/dropoutt-cli)** — Pre-flight checks for LLM training data. Local Python CLI that scans corpora for empty loss masks, broken conversational roles, truncation, contamination, and PII before burning a training run. Product Hunt #70.
- **[VegOps](https://github.com/ckproduces/VegOps)** — Autonomous multi-agent SRE incident response system. Monitors 5xx errors, executes a 3-agent diagnostic workflow, triggers automated recovery tools, and synthesizes team post-mortems.
- **[tokn](https://github.com/ckproduces/tokn)** — LLM-assisted workbench for designing, structuring, and synthesizing fine-tuning datasets from specifications and seed data.
- **[probabilistic-artificial-text-generator](https://github.com/ckproduces/probabilistic-artificial-text-generator)** — Character n-gram sequence model with temperature-scaled multinomial sampling, built from scratch to study sequence dynamics without neural nets.
- **[personal-website](https://github.com/ckproduces/personal-website)** — Personal site and engineering writing at [cagriokan.com](https://cagriokan.com).

*Also:* **[bulut](https://github.com/bulutai/bulut)** (multi-agent accessibility web agent) · **Manifold** (synthetic image/video data pipeline) · **EcoIstanbul** (AI-powered sustainable tourism).
